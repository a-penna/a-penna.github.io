# a-penna.github.io

Personal site with my iOS apps and their privacy policies / terms (EN + IT UI, documents in IT · EN · ES · FR · DE).

The site is plain static HTML generated by a small Python script — no framework, no runtime dependencies, no third-party requests (fonts are self-hosted).

## Edit & rebuild

```bash
python3 -m pip install markdown   # once
python3 src/build.py
```

| What | Where |
| --- | --- |
| Apps, descriptions, UI strings | `src/content.py` |
| Privacy policy / terms | `src/legal/<slug>/privacy-<lang>.md`, `terms-<lang>.md` |
| App icons (1024 px PNG) | `src/icons/<slug>.png` → converted to WebP (needs `cwebp`) |
| Styles / scripts | `src/site.css`, `src/site.js` |

An app without `terms-*.md` falls back to Apple's Standard EULA.

`app-ads.txt` at the root is required by AdMob — keep it.
